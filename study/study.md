→ Use a button, not a chip.

Why?

Chips are for filtering, selection within a set, or inline UI controls (e.g., “On/Off”, categories).

Choosing an input folder is a primary action, not a filter nor a small inline toggle.

It's also not a binary state toggle like on/off; you are triggering a picker.
